Proyecto 01 · Destacado · En Producción · Local-First · PWA

Nexus Library

Santuario bibliotecario personal con estética Dark Academia, arquitectura local-first soberana y sincronización cloud

🌐 Visitar App en Producción 🐙 Repositorio GitHub 🏛️ Portal de Arquitectura 🗺️ Atlas de Arquitectura (6 Capas) ⚡ Diagrama de Flujo Interactivo

¿Qué es?

Nexus Library es una plataforma web progresiva (PWA) de catalogación literaria y santuario bibliotecario desplegada en producción. Diseñada bajo una cuidada estética editorial Dark Academia, está pensada para coleccionistas y lectores voraces que buscan una experiencia cálida, táctil y privada.

Técnicamente, implementa un paradigma Local-First estricto: la base de datos local Dexie en IndexedDB es la fuente de verdad inmediata en el dispositivo del usuario, permitiendo un funcionamiento reactivo instantáneo e interactividad al 100% sin conexión a internet. Los datos se sincronizan de forma bidireccional y transparente con Supabase (PostgreSQL, Row-Level Security y Storage) en cuanto hay conexión de red, integrando notificaciones Web Push orquestadas mediante Edge Functions en Deno.

Catálogo de funcionalidades

📚
Estantería Ceremonial 3D

Mueble de roble tallado con hornacinas, lomos volumétricos interactivos, marcapáginas dinámicos y navegación táctil.

📖
Ficha de Libro Abierto

Despliegue ceremonial emulando un tomo abierto de dos páginas con pliegue central, costura física, sellos de lacre carmesí y animación FLIP.

🗺️
Atlas Literario Cartográfico

Mapa consular en SVG interactivo estilo siglo XIX que sella con tinta y banderas los países de origen de las obras y autores leídos.

⚡
Arquitectura Local-First Soberana

Persistencia inmediata en IndexedDB con Dexie.js y reactividad useLiveQuery. Modo invitado completo y migración transparente a la nube.

🔔
PWA Offline & Web Push

Instalable como app nativa con Service Worker (Cache Storage) y recepción de alertas y avisos en segundo plano vía Supabase Edge Functions y VAPID.

🎖️
Códice de la Orden Nexus

Escalafón honorífico de 10 rangos con cálculo determinista de experiencia (XP) sobre lecturas, páginas y retos, con carnet consular exportable.

Arquitectura Técnica y Módulos

Frontend SPA (React 18 + TS + Vite)Tipado TypeScript estricto, división en chunks con React.lazy/Suspense (bundle inicial ~389 kB) y hooks de orquestación desacoplados.
Almacenamiento Local (Dexie / IndexedDB)Fuente de verdad soberana en el cliente; consultas reactivas sin latencia de red ni bloqueos de interfaz.
Backend as a Service (Supabase Cloud)PostgreSQL con columnas JSONB e índices GIN, Row-Level Security (RLS) estricto por usuario y canales WebSocket en tiempo real.
Edge Functions & Push (Deno)Microservicio serverless en Deno (send-book-push) para el despacho cifrado de notificaciones Web Push firmadas con VAPID.
Calidad & Pruebas E2E (Playwright)Suite automatizada de tests End-to-End para autenticación, persistencia Dexie, alta de obras y regresión visual. Conformidad WCAG 2.2 AA.

Proyecto 02 · Flutter · GCP · Firebase · Serverless

Armario Virtual

App móvil con motor de IA en la nube para gestión inteligente del vestuario personal

🐙 GitHub

¿Qué es?

Armario Virtual va más allá del simple almacenamiento de imágenes. Integra un motor de Inteligencia Artificial en la nube para analizar, categorizar y recomendar prendas automáticamente. El procesamiento de imágenes usa Dart Isolates para no bloquear la interfaz, garantizando una experiencia completamente fluida mientras la IA trabaja en segundo plano.

Funcionalidades principales

🧥
Gestión de Inventario con IA

Subida de fotos con recorte automático de bordes transparentes y optimización de imagen. API externa integrada para eliminación de fondos dejando las prendas limpias visualmente.

🏷️
Auto-Tagging automático

Identifica el tipo de prenda ("Camiseta", "Vaqueros") y sus colores predominantes en RGB de forma automática. Confianza mínima del 70% garantizada por Vision API.

🛍️
Smart Shopping visual

Usa los tags generados por la IA para buscar y sugerir productos similares en la web en tiempo real mediante Google Custom Search API.

🌐
Traducción automática

Traduce las etiquetas detectadas del inglés al español con Translation API, filtrando términos irrelevantes como "textil" o "producto" mediante lista de exclusión personalizada.

👗
Probador Virtual (Fitting Room)

Interfaz Drag & Drop para componer outfits combinando parte superior, inferior y calzado. Validación de categorías esenciales antes de guardar.

🔐
Seguridad avanzada

Firebase Auth con Google Sign-In, Firebase App Check con Play Integrity contra tráfico abusivo y Secret Manager en GCP para gestión segura de claves API.

Arquitectura Cloud — GCP (europe-west1)

Cloud Functions (Python Gen 2)Backend serverless — lógica de IA completamente desacoplada del cliente
Vision APIEtiquetado automático con confianza >70% y extracción de colores RGB dominantes
Translation APITraducción EN→ES con filtro de exclusión personalizado por dominio
Custom Search APIMotor de búsqueda visual por tags para recomendación de productos similares
Cloud FirestoreBD NoSQL optimizada para lecturas en tiempo real por colección de usuario
Cloud StorageAlmacenamiento multimedia por usuario: garment_images/{userId}/
Firebase Auth + App CheckAutenticación con Google Sign-In y protección Play Integrity
Secret ManagerGestión segura de claves API sin exposición en código fuente

Gestión Genérica

Prácticas ViewNext — Ecosistema de 6 microservicios con CI/CD completo y despliegue en Azure

🐙 GitHub

¿Qué es?

Aplicación empresarial diseñada para gestionar operaciones genéricas, construida íntegramente bajo un paradigma de microservicios altamente escalable. Backend en Java Spring Boot y frontend en Node.js, con un entorno de despliegue continuo completamente automatizado. Desarrollada durante las prácticas en ViewNext.

Ecosistema de 6 microservicios

API GatewayEnrutamiento dinámico de todas las peticiones al microservicio correspondiente
User CRUDOperaciones completas de creación, lectura, actualización y eliminación de usuarios
Security ServiceImplementación de Spring Security para autenticación y autorización centralizada
Audit ServiceTrazabilidad de registros y accesos recibidos de forma asíncrona vía RabbitMQ
Exception ServiceManejo centralizado de excepciones personalizadas con respuestas HTTP estandarizadas
Discovery Service (Eureka)Service discovery para balanceo de carga interno entre microservicios

Comunicación asíncrona

Implementación de RabbitMQ como broker de mensajería para el envío de datos de registro y login hacia el servicio de auditoría. Esta arquitectura evita cuellos de botella en la autenticación y garantiza la trazabilidad sin penalizar el rendimiento de los servicios principales.

Infraestructura & DevOps

Entorno completamente dockerizado y desplegado en Azure con Kubernetes. El ciclo de vida del software está automatizado con pipelines de Jenkins y GitHub Actions para integración y despliegue continuo (CI/CD). El proyecto está respaldado con documentación funcional completa en wikis de GitHub.

Proyecto 05 · React · Tailwind CSS · Supabase · Zustand · PWA

Cheffy

Aplicación web progresiva "mobile-first" para la gestión inteligente de la despensa y recetario

🐙 Repositorio

¿Qué es?

Cheffy es una aplicación integral diseñada para facilitar la organización de las compras y la cocina en el hogar. Desarrollada con un enfoque "mobile-first" como PWA (Progressive Web App), permite a los usuarios gestionar su lista de la compra, activar un "modo compra" interactivo para el supermercado, llevar un control del inventario en la despensa y guardar sus recetas favoritas. Todo el sistema está respaldado por Supabase para ofrecer persistencia de datos en la nube de forma segura.

📋

Gestión rápida de artículos a comprar.

🛒
Modo Compra

Interfaz optimizada sin distracciones para usar en el supermercado.

🥫
Despensa

Control de stock e inventario de ingredientes en casa.

📖
Mis Platos / Recetas

Guarda, organiza y consulta tus platos favoritos.

🎨
UI/UX Moderna

Tema visual "Warm Cream" relajante con selector de iconos y emojis.

Arquitectura y Módulos

Frontend SPA (React + Vite)Arquitectura basada en componentes con enrutamiento dinámico para una experiencia de usuario fluida y sin recargas.
Gestión de Estado (Zustand)Manejo global del estado de la aplicación de forma ligera y eficiente, evitando el prop drilling.
Estilos y UI (Tailwind CSS)Diseño completamente responsive y utilidades CSS para mantener una interfaz consistente en cualquier dispositivo.
Backend as a Service (Supabase)Gestión de base de datos relacional (PostgreSQL), autenticación de usuarios y políticas de seguridad integradas.

Infraestructura & DevOps

La aplicación está construida como una PWA (Progressive Web App), lo que permite a los usuarios instalarla directamente en sus dispositivos móviles y ordenadores como si fuera una aplicación nativa. La infraestructura de datos está gestionada de forma serverless a través de Supabase, garantizando alta disponibilidad y sincronización eficiente.
